KC7 Investigation Patterns (Core Analyst Thinking)

// 1. Pivoting between datasets
Email
| join kind=inner Employees on $left.Sender == $right.Email

// 2. Finding anomalies over time
AuthenticationEvents
| summarize Attempts=count() by bin(TimeGenerated, 1h), User

// 3. Suspicious external communication
OutboundNetworkEvents
| where Url has_any ("pastebin", "discord", "ngrok", "webhook")

// 4. File staging behavior
FileCreationEvents
| summarize FileCount=count() by FolderPath
| where FileCount > 500

KC7-Style SOC Hunting Scenarios

1. Password Spray Detection

AuthenticationEvents
| where Result == "Fail"
| summarize FailCount=count() by IPAddress, User
| where FailCount > 20

2. Phishing Email Tracking

Email
| where Subject has "urgent" or Subject has "password"
| join kind=inner Employees on Sender

3. Malware Execution Chain

ProcessEvents
| where ProcessName in ("powershell.exe", "cmd.exe", "wscript.exe")
| where CommandLine has "http" or CommandLine has "download"

4. Data Exfiltration Pattern

OutboundNetworkEvents
| where Url has_any ("drive.google.com", "dropbox", "mega.nz")
| summarize count() by Device, Url

Advanced SOC KQL Patterns

// Time-based anomaly detection
SigninLogs
| summarize Attempts=count() by bin(TimeGenerated, 1h)

// Rare process execution
DeviceProcessEvents
| summarize count() by FileName
| top 10 by count_

// DNS-based detection
PassiveDns
| where Domain endswith ".ru" or Domain endswith ".cn"

Analyst Notes

  • KC7 labs simulate real SOC workflows using simplified but realistic datasets
  • Primary skill is pivoting between tables, not memorizing syntax
  • Most investigations start with: where → summarize → join
  • Behavioral patterns matter more than single indicators
