Sysmon
Filter Cheat Sheet

Complete reference for all Sysmon event IDs, filterable fields, conditions, and XML rule syntax.

Sysmon v15.x compatible
Rule structure
<RuleGroup name="" groupRelation="or"> <EventFiltering> <ProcessCreate onmatch="include"> <Image condition="end with">powershell.exe</Image> </ProcessCreate> </EventFiltering> </RuleGroup>
onmatch values
include → log if rule matches exclude → suppress if rule matches ; Default behavior when no rule matches: ; include → event is excluded (not logged) ; exclude → event is included (logged)
groupRelation
or → match if ANY field matches and → match if ALL fields match ; Applied per EventFilter block ; Multiple rules → logical OR between ; rule groups by default
CLI commands
# Install with config sysmon -i config.xml -accepteula # Update config sysmon -c config.xml # Uninstall sysmon -u # Show schema sysmon -s

<Sysmon schemaversion="4.90"> <!-- Hash algorithms to capture (comma-separated) --> <HashAlgorithms>md5,sha256,imphash</HashAlgorithms> <!-- Archive deleted executables (EID 23) --> <ArchiveDirectory>C:\Sysmon\Archive</ArchiveDirectory> <EventFiltering> <!-- EID 1: Log powershell.exe launches --> <RuleGroup name="" groupRelation="or"> <ProcessCreate onmatch="include"> <Image condition="image">powershell.exe</Image> <Image condition="image">pwsh.exe</Image> </ProcessCreate> </RuleGroup> <!-- EID 3: Network connections — exclude known good --> <RuleGroup name="" groupRelation="or"> <NetworkConnect onmatch="exclude"> <Image condition="image">svchost.exe</Image> <DestinationPort condition="is">53</DestinationPort> </NetworkConnect> </RuleGroup> <!-- EID 10: LSASS access detection --> <RuleGroup name="" groupRelation="or"> <ProcessAccess onmatch="include"> <TargetImage condition="image">lsass.exe</TargetImage> <GrantedAccess condition="contains any">0x1010|0x1410|0x143a|0x1fffff</GrantedAccess> </ProcessAccess> </RuleGroup> </EventFiltering> </Sysmon>
