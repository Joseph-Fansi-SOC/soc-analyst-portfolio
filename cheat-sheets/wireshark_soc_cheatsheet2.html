🚨 ARP Spoofing Indicator
Same IP with different MAC addresses appearing in ARP replies = active MITM
⚠️ Gratuitous ARP
ARP reply sent without request. Could be legit (IP change) or attack (poisoning)
🚨 DHCP Spoofing
Multiple DHCP OFFER responses = rogue DHCP server = gateway hijack
⚠️ MAC Flooding
Huge number of unique MACs = CAM table overflow = switch becomes hub
