KQL Fundamentals

Field Value Match Syntax

Match an exact field value. The bread-and-butter of KQL filtering.

event.outcome:"failure"
field:valuebasic
Boolean AND / OR / NOT Syntax

Combine multiple conditions. AND narrows results; OR widens them; NOT excludes.

event.category:"authentication" AND event.outcome:"failure" AND NOT user.name:"serviceaccount"
booleanlogic
Wildcard Search Syntax

Use * for multi-char wildcard or ? for single-char wildcard.

process.name:*mimikatz*
user.name:admin?
wildcardpattern
Range Queries (Numeric & Date) Syntax

Filter by numeric ranges (ports, status codes) or time windows.

http.response.status_code >= 400 AND http.response.status_code <= 599
@timestamp >= "now-24h"
rangetimestamp
Field Exists Check Syntax

Check whether a field is present or absent in a document.

process.parent.name:*
NOT user_agent.name:*
existsnull check
Nested Field (Dot Notation) Syntax

Access nested ECS fields using dot notation for deep field paths.

threat.enrichments.indicator.type:"ip-addr"
kubernetes.pod.name:nginx*
nestedECS

Authentication & Login Events

Brute Force — Multiple Failed Logins Critical

Detect repeated authentication failures from the same source. Tune threshold in Kibana alerting.

event.category:"authentication" AND event.outcome:"failure"
brute-forceauthMITRE T1110
Successful Login After Multiple Failures Critical

Pivot on a user who had failures and then succeeded — strong brute-force signal.

event.category:"authentication" AND event.outcome:"success" AND source.ip:*
brute-forcecompromiseMITRE T1078
Admin / Privileged Account Login High

Monitor logins from privileged or administrative accounts, especially outside business hours.

event.category:"authentication" AND event.outcome:"success" AND (user.name:*admin* OR user.name:*administrator*)
privilegeadminMITRE T1078.002
Login Outside Business Hours High

Logins at unusual times. In KQL use time filter in Kibana UI (e.g. 11 PM–6 AM range).

event.category:"authentication" AND event.outcome:"success" AND @timestamp >= "now-1d/d"
after-hoursanomaly
Windows EventID 4625 — Failed Logon High

Windows Security Event ID for failed logon attempts. Maps to brute-force detection.

event.code:"4625" AND event.provider:"Microsoft-Windows-Security-Auditing"
windowseventid4625
Windows EventID 4648 — Explicit Credential Use High

Logon attempt using explicit credentials (e.g., RunAs). Common in pass-the-hash attacks.

event.code:"4648" AND event.provider:"Microsoft-Windows-Security-Auditing"
pass-the-hashrunas4648

Network Detection

Suspicious DNS Queries High

Detect DNS lookups to known suspicious TLDs or unusually long hostnames (DGA detection).

event.category:"dns" AND (dns.question.name:*.xyz OR dns.question.name:*.tk OR dns.question.name:*.top)
dnsDGAC2MITRE T1071.004
DNS over Non-Standard Port (DNS Tunneling) Critical

DNS tunneling often uses non-standard ports. Standard DNS is UDP/TCP port 53.

network.protocol:"dns" AND NOT destination.port:53
dns-tunnelexfilMITRE T1071.004
Large Outbound Data Transfer Critical

High outbound bytes may indicate data exfiltration. Adjust threshold per your baseline.

network.direction:"egress" AND destination.bytes > 10000000
exfiltrationlarge-transferMITRE T1041
Connection to Non-Standard HTTP Ports Medium

C2 channels often use HTTP/HTTPS on non-standard ports to evade detection.

network.protocol:"http" AND NOT (destination.port:80 OR destination.port:8080 OR destination.port:443)
C2httpMITRE T1071.001
Internal Host Port Scanning High

A single source IP connecting to many destination ports on different hosts — scan behavior.

event.category:"network" AND network.direction:"internal" AND event.action:"connection_attempted"
scanreconMITRE T1046
Tor / Known Proxy IP Connections High

Filter for connections to/from known Tor exit nodes or anonymizing proxy ranges.

threat.indicator.type:"ip-addr" AND threat.indicator.marking.tlp:*
torproxyanonymizer
Beaconing — Periodic C2 Connections Critical

Look for repeated outbound connections at regular intervals to the same external IP/domain.

event.category:"network" AND network.direction:"egress" AND network.transport:"tcp" AND destination.port:(443 or 80 or 8443)
beaconingC2MITRE T1071
HTTP 4xx / 5xx Error Spike Medium

Sudden spike in HTTP errors can indicate scanning, fuzzing, or application attacks.

http.response.status_code >= 400 AND http.response.status_code <= 599 AND source.ip:*
webhttp-errorsfuzzing

Malware, Process & Endpoint

Suspicious Process Execution Critical

Detect execution of common offensive tools by name. Expand list as needed.

event.category:"process" AND event.type:"start" AND process.name:(*mimikatz* OR *cobalt* OR *meterpreter* OR *psexec*)
malwareoffensive-toolsMITRE T1059
PowerShell Suspicious Execution Critical

Encoded, hidden, or bypassed PowerShell execution — common malware delivery vector.

process.name:"powershell.exe" AND process.args:(*-enc* OR *-EncodedCommand* OR *-nop* OR *bypass* OR *hidden*)
powershellencodedMITRE T1059.001
cmd.exe Spawned by Office App Critical

Office macro-based malware spawns cmd/powershell. Classic phishing-to-execution chain.

process.name:("cmd.exe" OR "powershell.exe") AND process.parent.name:("winword.exe" OR "excel.exe" OR "outlook.exe")
macrophishingMITRE T1566.001
Credential Dumping (LSASS Access) Critical

Access to lsass.exe is a strong indicator of credential dumping activity.

event.category:"process" AND process.name:"lsass.exe" AND event.action:"accessed"
credential-dumplsassMITRE T1003.001
Script Interpreters Execution High

Detect execution of script interpreters often used in Living-off-the-Land attacks.

event.category:"process" AND process.name:("wscript.exe" OR "cscript.exe" OR "mshta.exe" OR "regsvr32.exe")
lolbaswscriptMITRE T1218
Ransomware — Mass File Modification Critical

Rapid file modifications/renames across many files is a ransomware behavioral signature.

event.category:"file" AND event.action:("rename" OR "overwrite") AND file.extension:(*.locked* OR *.enc* OR *.crypto*)
ransomwarefileMITRE T1486

Lateral Movement

PsExec / Remote Service Creation Critical

PsExec creates a remote service. EventID 7045 + network source is a strong lateral movement indicator.

event.code:"7045" AND winlog.event_data.ServiceName:*psexec*
psexeclateralMITRE T1021.002
WMI Remote Execution Critical

WMI is a common LOLBin for remote execution and lateral movement.

process.name:"wmiprvse.exe" AND event.type:"start" AND process.parent.name:"svchost.exe"
wmilolbasMITRE T1047
RDP Lateral Movement (EventID 4624 Type 10) High

Logon type 10 = RemoteInteractive (RDP). Cross-reference with source IP for lateral movement.

event.code:"4624" AND winlog.event_data.LogonType:"10"
rdp4624MITRE T1021.001
Pass-the-Hash / Pass-the-Ticket Critical

Network logon (Type 3) with NTLM auth from non-standard process is a PTH indicator.

event.code:"4624" AND winlog.event_data.LogonType:"3" AND winlog.event_data.AuthenticationPackageName:"NTLM"
pthntlmMITRE T1550.002

Data Exfiltration

Anomalous Upload Volume to External IP Critical

High source bytes sent to a public, non-RFC1918 destination — classic exfiltration pattern.

source.bytes > 5000000 AND NOT (destination.ip:"10.0.0.0/8" OR destination.ip:"192.168.0.0/16" OR destination.ip:"172.16.0.0/12")
exfiluploadMITRE T1041
DNS Exfiltration (Long Subdomain) Critical

DNS exfil encodes data in long subdomain labels. Look for unusually long DNS query names.

event.category:"dns" AND dns.question.name:*.*.*.*.*.*
dns-exfilsubdomainMITRE T1048.003
Cloud Storage Upload (S3 / OneDrive / Dropbox) High

Connections to cloud storage providers from endpoints may indicate staged exfiltration.

event.category:"network" AND (destination.domain:*.s3.amazonaws.com OR destination.domain:*.dropbox.com OR destination.domain:*onedrive*)
clouds3MITRE T1567

(source.ip:"185.220.101.0/24" OR destination.ip:"185.220.101.0/24")

process.hash.sha256:"<replace-with-sha256>" OR file.hash.sha256:"<replace-with-sha256>"

Key Windows Event IDs

EventID 4688 — Process Creation Medium

New process creation. Requires "Audit Process Creation" GPO. Rich execution telemetry.

event.code:"4688" AND winlog.event_data.NewProcessName:*
process4688windows
EventID 4698 — Scheduled Task Created High

Attackers create scheduled tasks for persistence. Any new task deserves scrutiny.

event.code:"4698" AND event.provider:"Microsoft-Windows-Security-Auditing"
persistence4698MITRE T1053.005
EventID 1102 — Audit Log Cleared Critical

Security audit log cleared — a major indicator of attacker cover-up activity.

event.code:"1102" OR event.code:"104"
log-clearcover-tracksMITRE T1070.001
EventID 4720 — User Account Created High

New local or domain account creation. Attackers create backdoor accounts for persistence.

event.code:"4720" AND event.provider:"Microsoft-Windows-Security-Auditing"
accountpersistenceMITRE T1136
EventID 4732 — Added to Privileged Group Critical

A user was added to a security-enabled local group (e.g., Administrators). Privilege escalation.

event.code:"4732" AND winlog.event_data.GroupName:"Administrators"
privilege-escalation4732MITRE T1078
Sysmon EventID 3 — Network Connection Medium

Sysmon captures process-level network connections. Pair with process name for high-value hunts.

event.code:"3" AND event.provider:"Microsoft-Windows-Sysmon" AND destination.port:(443 OR 80 OR 4444)
sysmonnetworkprocess
Sysmon EventID 11 — File Created Medium

Track file creation events in sensitive directories (Temp, Startup, etc.).

event.code:"11" AND event.provider:"Microsoft-Windows-Sysmon" AND file.path:(*\\Temp\\* OR *\\Startup\\* OR *\\AppData\\Roaming\\*)
sysmonfiletemp
