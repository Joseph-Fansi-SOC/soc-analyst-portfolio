Threat Hunting Queries
HuntWhat You're Looking ForSPL Query
First-Seen Executables New binaries never seen before on a host index=* sourcetype=Sysmon EventCode=1 | stats min(_time) as first_seen by Image, host | eval age_days=round((now()-first_seen)/86400,1) | where age_days < 1 | sort first_seen
Rare Parent-Child Combos Process relationships that almost never occur index=* sourcetype=Sysmon EventCode=1 | stats count by ParentImage, Image | where count < 5 | sort count
Long-Running Processes Processes active far longer than expected index=* sourcetype=Sysmon EventCode=1 | eval age=now()-_time | where age > 86400 | stats count by host, Image, User | sort -age
Unusual Listening Ports New services binding to unexpected ports index=* sourcetype=netstat state=LISTEN | where NOT (port=80 OR port=443 OR port=3389 OR port=445) | stats count by host, port, process | sort -count
Repeated Failed + 1 Success Classic brute force leading to compromise index=* EventCode=4625 | stats count as failures by TargetUserName, IpAddress | where failures >= 5 | join TargetUserName [search index=* EventCode=4624 | dedup TargetUserName] | table TargetUserName, IpAddress, failures
Spike Detection Statistically abnormal event volume index=* sourcetype=WinEventLog:Security | timechart span=1h count | streamstats avg(count) as avg, stdev(count) as std | eval upper_bound=avg+(std*3) | where count > upper_bound
New Hosts on Network Devices that appeared in the last 24h index=* earliest=-24h | stats min(_time) as first_seen by host | eval age_h=round((now()-first_seen)/3600,1) | where age_h < 24 | sort first_seen
Stacking — Rare Usernames Hunt for infrequently used accounts index=* sourcetype=WinEventLog:Security EventCode=4624 | stats count by TargetUserName | sort count | head 20
Incident Response Runbook Queries
💡 Use these sequentially to triage and scope an active incident.
IR StepGoalSPL Query
1. Scope Affected Hosts Find all machines involved index=* (src_ip="<IOC_IP>" OR dest_ip="<IOC_IP>" OR host="<IOC_HOST>") | stats count by host, sourcetype | sort -count
2. Scope Affected Users Identify all users on compromised host index=* host="<COMPROMISED_HOST>" | stats values(user) as users, count by host, sourcetype | table host, users
3. Timeline of Events Reconstruct attacker activity index=* host="<COMPROMISED_HOST>" earliest=-48h | table _time, sourcetype, EventCode, user, src_ip, CommandLine, Image | sort _time
4. Processes Spawned What did the attacker run? index=* host="<COMPROMISED_HOST>" sourcetype=Sysmon EventCode=1 earliest=-24h | table _time, User, Image, CommandLine, ParentImage, ParentCommandLine | sort _time
5. Files Dropped New files created on the host index=* host="<COMPROMISED_HOST>" sourcetype=Sysmon EventCode=11 earliest=-24h | table _time, User, TargetFilename | sort _time
6. Network Connections Made External comms from compromised host index=* host="<COMPROMISED_HOST>" sourcetype=Sysmon EventCode=3 earliest=-24h | where NOT cidrmatch("10.0.0.0/8",DestinationIp) AND NOT cidrmatch("192.168.0.0/16",DestinationIp) | table _time, Image, DestinationIp, DestinationPort, User
7. Lateral Movement Check Did attacker pivot to other hosts? index=* EventCode=4624 LogonType=3 | where SubjectUserName="<COMPROMISED_USER>" | stats dc(ComputerName) as targets, values(ComputerName) as machines by SubjectUserName | where targets > 1
8. Persistence Check Did they leave a backdoor? index=* host="<COMPROMISED_HOST>" earliest=-48h (EventCode=4698 OR EventCode=7045 OR (sourcetype=Sysmon EventCode=13 TargetObject="*Run*")) | table _time, EventCode, host, User, TaskName, ServiceName, TargetObject, Details
9. Data Exfil Check Was data stolen? index=* host="<COMPROMISED_HOST>" sourcetype=firewall OR sourcetype=proxy earliest=-48h | stats sum(bytes_out) as total by dest_ip | eval MB=round(total/1024/1024,2) | where MB > 10 | sort -MB
10. IOC Sweep (Network-wide) Find IOC across ALL hosts index=* earliest=-7d | where src_ip="<IOC_IP>" OR dest_ip="<IOC_IP>" OR match(CommandLine,"<IOC_HASH_OR_STRING>") | stats count by host, user, sourcetype | sort -count

Search Optimization Tips
TipWhy It HelpsExample
✔ DO Specify index= Restricts scan to targeted data index=windows sourcetype=WinEventLog:Security
✔ DO Narrow time range Less disk I/O = dramatically faster earliest=-1h latest=now
✔ DO Filter before pipe Reduce event volume early in pipeline index=* EventCode=4625 | stats count by user
✔ DO Use fields early Drop unneeded fields to cut memory | fields host, user, action, _time
✔ DO Use summary indexes Pre-aggregated data for dashboards index=summary report=daily_logins | stats sum(count) by user
✖ AVOID Leading wildcards Cannot leverage the index efficiently *error* → use: sourcetype=syslog error
✖ AVOID table before stats table should come at the end of a pipeline | stats count by user | sort -count | table user, count
✖ AVOID NOT with wildcards Very expensive; use != or where clause | where user!="service_account"
⚡ TIP Use tstats for speed Queries index metadata — extremely fast | tstats count WHERE index=windows by host, _time span=1h
⚡ TIP Accelerate reports Enable report acceleration for recurring searches Settings → Searches → Enable acceleration on saved searches
🔍 HUNT Use subsearch wisely Limit subsearch results to <10k for performance | join user [search index=hr | head 1000]
