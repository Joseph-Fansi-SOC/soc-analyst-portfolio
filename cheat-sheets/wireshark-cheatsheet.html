Useful Combinations

ip.addr==10.0.0.1 && tcp TCP from/to specific host
tcp.port==80 || tcp.port==443 All web traffic
!arp && !dns && !icmp Exclude noisy protocols
tcp.flags.syn==1 && ip.src==x.x.x.x New connections from host
http && ip.addr==1.2.3.4 HTTP to/from specific IP
dns && !ip.dst==8.8.8.8 DNS not going to Google
tcp.analysis.retransmission || tcp.analysis.lost_segment Network quality issues
frame.time_delta > 1 Gaps > 1 second between packets

💡 Quick Tips

  • Display filters work on captured packets; capture filters (BPF) limit what's recorded — apply capture filters first.
  • Right-click any field in the packet detail pane → Apply as Filter to build filters automatically.
  • Use Follow → TCP Stream (Ctrl+Alt+Shift+T) to reconstruct full conversations.
  • Statistics → Conversations gives a quick bandwidth-by-host overview.
  • Save complex display filters with Analyze → Display Filter Macros.
  • Use frame.number, frame.len, and frame.time for packet-level meta filtering.
  • Colorization rules are at View → Coloring Rules — use the same syntax as display filters.
  • tshark -r file.pcap -Y "display_filter" applies display filters from the command line.
