# Lessons Learned

## Key Takeaways

* Supply-chain attacks can compromise trusted software updates.
* DLL Side-Loading remains an effective execution technique.
* Malware increasingly relies on in-memory execution and encryption to evade detection.
* Threat intelligence platforms accelerate malware attribution.

---

## Detection Opportunities

* Monitor unexpected DLL loads by trusted applications.
* Verify software updates using digital signatures.
* Hunt for DLL Side-Loading activity (MITRE T1574).
* Monitor suspicious outbound connections following software updates.
