# 3CX Supply Chain Investigation

## Scenario
Investigated indicators associated with the 3CX supply-chain compromise using endpoint and network telemetry.

## Objectives
- Identify malicious activity
- Analyze artifacts
- Document Indicators of Compromise (IOCs)
- Map techniques to MITRE ATT&CK
- Recommend detection opportunities

## Skills Demonstrated
- Threat Hunting
- Malware Analysis
- IOC Analysis
- MITRE ATT&CK Mapping
- Incident Documentation
