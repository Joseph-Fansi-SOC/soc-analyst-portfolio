# Lespion Insider Threat Investigation (Insider Threat / OSINT)

## Executive Summary

This investigation analyzes a suspected insider threat incident involving exposed credentials, leaked API keys, cryptocurrency mining activity, and open-source intelligence (OSINT) analysis.

The investigation demonstrates how publicly available information from GitHub repositories, social media platforms, and image intelligence tools can be correlated to identify compromised accounts, exposed secrets, and attacker activity.

---

## Investigation Scenario

A client experienced a network compromise that was traced back to a single user account. Initial findings suggested possible insider involvement.

The objective was to investigate the user's digital footprint, identify exposed information, determine attack actions, and collect intelligence related to the incident.

---

## Investigation Objectives

* Identify exposed credentials in GitHub repositories.
* Analyze leaked API keys and passwords.
* Investigate attacker activity and tooling.
* Correlate online identities using OSINT techniques.
* Perform image-based intelligence analysis.
* Document findings and defensive recommendations.

---

## Investigation Approach

The investigation used open-source intelligence techniques:

* GitHub repository analysis
* Credential exposure analysis
* Base64 password decoding
* Social media investigation
* Image reverse searching
* Location intelligence
