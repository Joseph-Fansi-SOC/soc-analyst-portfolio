# Lessons Learned

## Key Takeaways

* Public repositories can unintentionally expose sensitive credentials.
* Organizations should implement secret scanning and code review processes.
* OSINT techniques are valuable during insider threat investigations.
* Digital footprints can provide critical investigative evidence.

---

## Detection Opportunities

* Monitor GitHub and public repositories for company-related secrets.
* Deploy automated secret scanning tools.
* Investigate unusual cryptocurrency mining activity.
* Monitor accounts for suspicious authentication activity.

---

## Defensive Recommendations

* Never commit API keys or passwords to source-control repositories.
* Rotate exposed credentials immediately.
* Enable multi-factor authentication.
* Implement secure development practices.
* Provide security awareness training.
