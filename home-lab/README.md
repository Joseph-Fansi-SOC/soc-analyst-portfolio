## Home Lab — Personal SOC environment
Built: 2025

A personal SOC environment built to practise real-world 
threat detection, log analysis and incident response.
Also used to investigate real security cases for friends and family.

### Tools
- Splunk — SIEM, detection rules, dashboards
- Wazuh — host-based intrusion detection (HIDS)
- Wireshark — network packet analysis
- AI tools for SOC analysis
