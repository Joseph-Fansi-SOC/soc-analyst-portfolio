# AI Usage Disclosure

## Purpose

Artificial Intelligence (AI) was used responsibly throughout the development of this cybersecurity portfolio as a learning, documentation, and productivity aid.

The purpose of using AI was to improve the quality, organization, and readability of investigation reports—not to replace hands-on technical analysis or decision-making.

---

# How AI Was Used

AI assisted with:

- Improving technical writing and grammar
- Formatting reports using GitHub Markdown
- Organizing investigation findings
- Creating investigation templates
- Structuring IOC documentation
- Assisting with MITRE ATT&CK mapping
- Explaining unfamiliar malware techniques and Windows internals
- Reviewing KQL and Sigma syntax
- Brainstorming detection opportunities

---

# Tasks Performed Independently

The following work was completed manually:

- Malware investigation
- Threat hunting
- Network traffic analysis
- IOC validation
- Wireshark analysis
- VirusTotal investigations
- ANY.RUN sandbox analysis
- MalwareBazaar research
- ThreatFox lookups
- MITRE ATT&CK verification
- Building and maintaining the home SOC lab
- Writing detection logic
- Testing KQL queries

Every technical conclusion published in this portfolio was reviewed and validated by me before documentation.

---

# Ethical Use of AI

AI was used as a professional assistant to:

- improve documentation quality,
- accelerate repetitive tasks,
- organize technical information, and
- enhance learning.

AI was **not** used to fabricate investigation results or replace independent analysis.

---

# Continuous Learning

As AI becomes increasingly integrated into Security Operations Centers (SOCs), I believe cybersecurity professionals should understand how to use AI responsibly while maintaining strong analytical and investigative skills.

This portfolio reflects that philosophy by combining hands-on technical investigations with transparent AI-assisted documentation practices.
