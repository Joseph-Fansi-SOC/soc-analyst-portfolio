# 🔍 AI Reconnaissance Automation

One of my ongoing projects is an **AI-assisted reconnaissance workflow** built using **Claude Code** and **ChatGPT**.

The workflow automates much of the repetitive OSINT collection process for investigations involving:

- Domains
- Email addresses
- IP addresses
- Organizations

Rather than manually performing dozens of searches, the workflow gathers, organizes, and structures publicly available intelligence into a consistent investigation report.

### Current Capabilities

- Domain reputation lookup
- WHOIS collection
- DNS enumeration
- MX & SPF record analysis
- Email address reconnaissance
- Breach exposure research
- Infrastructure profiling
- Investigation report generation

This workflow is designed to support:

- Incident Response
- Threat Intelligence
- Phishing Investigations
- Email Security Investigations
- Threat Hunting

> **All reconnaissance activities rely exclusively on publicly available information (OSINT) and are intended for defensive cybersecurity, incident response, and threat intelligence purposes.**
