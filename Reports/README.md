# 📊 Reporting Methodology

My reports follow a SOC-style investigation structure:

## 1. Alert

Document:

- Detection source
- Alert type
- Severity
- Initial indicators

Example:

```
Source:
SIEM / IDS / Security Tool

Alert:
Suspicious network activity detected
```

---

## 2. Investigation

Document:

- Evidence collected
- Logs analyzed
- Tools used
- Indicators discovered

Examples:

- PCAP analysis
- Windows Event Logs
- Malware analysis
- Threat intelligence lookup
- IOC investigation

---

## 3. Analysis

Document:

- Attack chain reconstruction
- Root cause
- Threat actor behavior
- False positive validation
- Security impact

---

## 4. MITRE ATT&CK Mapping

Each investigation includes:

- Tactic
- Technique ID
- Technique description
- Evidence observed

Example:

```
T1021.002
SMB/Windows Admin Shares

T1059
Command and Scripting Interpreter
```

---

## 5. Response Recommendations

Reports include defensive recommendations:

- Containment actions
- Detection improvements
- Blocking recommendations
- Security hardening
- Lessons learned
